# 할 일 목록

출근(`/day-start`)·회의(`/meeting-intake`)·퇴근(`/daily-log`)·주간(`/weekly-report`) 스킬이 함께 읽고 쓰는 단일 원본이다.

## 규칙

- 한 줄이 할 일 하나다. 형식: `- T-NNN 제목 | 출처: <경로 §절> | 지시: <사람> | 기한: YYYY-MM-DD | 과제: <projects 폴더명> | 트래커: #<번호 또는 ->`
  - `출처` 는 필수다. 회의록이면 `meetings/<폴더> §<절>`, 구두 지시면 `구두 YYYY-MM-DD <사람>`, 스스로 정한 일이면 `자체`.
  - `지시`·`기한`·`과제` 는 없으면 칸을 지운다. `트래커` 는 등록 전이면 `-`.
  - `대기` 항목은 `막힌 이유:`, `요청 대상:`, `요청일: YYYY-MM-DD` 칸을 덧붙인다.
  - `완료`·`취소` 항목은 `완료: YYYY-MM-DD` 또는 `취소: YYYY-MM-DD 사유` 를 덧붙인다.
- ID 는 한 번 붙이면 바꾸지 않고 재사용하지 않는다. 새 ID 는 `다음 ID` 값을 쓰고 1 올린다.
- 상태 이동은 줄을 해당 섹션으로 옮겨서 표시한다.
- `완료`·`취소` 섹션은 주간보고(`/weekly-report`) 후 `## 지난 완료` 로 내린다.
