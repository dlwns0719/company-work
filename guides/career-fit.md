# career-fit — 업무 커리어 적합성 평가

## 목적

사용자가 제공한 **현재 또는 앞으로 맡을 업무** 를 `career/career-path.md` 의 루브릭으로 채점한다. **점수 + 근거 + 갭/액션** 을 산출한다. 업무 설명 외 다른 파일은 변경하지 않는다.

## 입력

`$ARGUMENTS` = 평가할 업무 설명. 다음 중 어느 형태든 받는다.

- 자유 서술 (한 문단~여러 문단)
- `career/career-path.md` §7 의 9항목 양식
- 업무 설명이 담긴 MD 파일 경로 (이 경우 Read 로 읽는다)

인자가 비어 있으면 §7 입력 양식을 보여주고 업무 설명을 요청한 뒤 종료한다.

## Step

### Step 1 — 기준 문서 로드

`career/career-path.md` 를 Read 로 읽는다. 이 문서가 채점 기준이다. 다음 섹션을 사용한다.

- §5 핵심 역량 축과 가중치 (7개 축, 만점)
- §6 점수→판정 기준
- §7 입력 양식 (9항목)
- §8 출력 양식
- §9~§13 강화 방법·강점·보완 역량 (갭/액션 근거)
- §15 최종 판단 원칙 (채점 근거 질문)

기준 문서가 없으면 "기준 문서 `career/career-path.md` 없음. 먼저 생성해야 한다." 로 보고하고 종료한다.

### Step 2 — 입력 정규화

사용자 업무 설명을 §7 의 9항목으로 매핑한다.

| 항목 | 비고 |
|---|---|
| 업무명 / 업무 설명 / 사용 기술 / 산출물 | 서술에서 추출 |
| 내가 맡는 역할 / 반복성·자동화 가능성 | 서술에서 추출 |
| Agent·Tool Calling·State·Evaluation·Platform 관련성 | 채점 핵심 입력 |
| Robotics·Physical AI·Simulation 직접/간접 관련성 | 채점 핵심 입력 |
| 이력서 문장 후보 | 없으면 Step 5 에서 생성 |

추출 불가 항목은 **"정보 부족"** 으로 명시한다. 채점에 치명적인 항목(마지막 두 관련성 항목)이 비면 사용자에게 **1회** 보충 질문을 한다. 그래도 없으면 보수적으로 낮게 채점하고 한계로 남긴다.

### Step 3 — 축별 채점

§5 의 7개 축 각각에 대해 **0 ~ 만점** 범위 점수를 매긴다. 각 점수에는 업무 설명에서 끌어온 **근거 1줄** 을 붙인다. §15 의 7개 질문을 근거 판단에 활용한다.

- 근거 없는 가점 금지. 업무에 없는 요소는 0점에 가깝게 둔다.
- 과대평가 금지 — "확장하면 가능" 은 현재 점수가 아니라 Step 5 액션으로 분리한다.

### Step 4 — 총점·판정

7개 축 점수를 합산(최대 100)하고 §6 구간으로 판정한다(매우 적합 / 적합 / 보조적 적합 / 낮은 적합 / 부적합).

### Step 5 — 갭/액션 도출

- **강화 방법**: §10 매핑표와 §9 예시를 근거로, 이 업무를 Physical AI / Robotics 방향으로 끌어올리는 구체 액션 2~4개.
- **보완 역량 연결**: 점수가 낮은 축을 §13 우선순위와 연결한다.
- **이력서 문장**: 이 업무로 남길 수 있는 표현 1~2개.
- **주의할 점**: §11 의 저적합 패턴에 빠질 위험이 있으면 경고한다.

### Step 6 — 출력

`career/career-path.md` §8 출력 양식 그대로 작성한다. 축별 점수 표의 근거 칸을 반드시 채운다. 점수는 `획득 / 만점` 형식.

## 금지

- 기준 문서(§5 가중치·§6 임계값)를 무시한 임의 채점
- 업무에 없는 역량을 있다고 가정한 가점
- 강화 가능성(미래)을 현재 점수에 반영
- 평가 외 레포 파일 수정 (기준 문서·커맨드 파일 등)
