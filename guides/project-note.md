# project-note — 과제 폴더 정리

## 목적

일을 하다 보면 보고 자료·조사 메모·그림이 날짜 이름으로 쌓인다. 둘 곳이 정해져 있지 않으면 임시 폴더가 생기고,
일지의 근거 경로가 제각각이 되고, 나중에 "가장 최근 보고 자료가 뭐였지" 를 찾게 된다.
이 스킬은 **과제 하나에 폴더 하나, 폴더마다 목차 하나**를 유지한다.

```text
records/projects/<slug>/
├── README.md        목차: 한 줄 설명 · 지금 상태 · 최신 문서 · 문서 목록 · 관련 회의
├── <문서들>          파일 이름은 <주제>-YYYY-MM-DD.md 를 권한다. 이미 있는 이름은 바꾸지 않는다
├── diagrams/        그림 원본과 내보낸 이미지
├── cases/, raw/     조사 원자료 (필요할 때만)
└── old/             지난 판. 지우지 않고 옮긴다
```

## 입력

`$ARGUMENTS` = `<모드> [slug] [대상]`

| 모드 | 하는 일 |
|---|---|
| `new <slug> [과제 이름]` | 과제 폴더와 README.md 를 만든다 |
| `add <slug> <파일 ...>` | 파일을 그 과제 폴더로 옮기고 목차에 올린다 |
| `index [slug]` | 목차를 실제 파일과 맞춘다. slug 가 없으면 모든 과제 |
| `sweep` | 과제 폴더 밖에 흩어진 문서를 찾아 어느 과제로 보낼지 제안한다 |

모드가 없으면 `index` 로 본다. `<slug>` 는 영문 소문자·하이픈이다.

## Step

### Step 1 — 현재 상태 파악

1. `records/projects/` 의 폴더와 각 `README.md` 머리말(`status`·`updated`·`todo`)을 읽는다.
2. `records/todo.md` 에서 `과제: <slug>` 칸이 붙은 항목을 과제별로 모은다.
3. 모드에 필요한 대상 파일을 확인한다. 과제 수·대상 파일 수를 1줄로 보고한다.

### Step 2 — 모드별 실행

**new** — 폴더를 만들고 `templates/project-readme.md` 를 복사해 이름·날짜를 채운다. 같은 slug 가 있으면 만들지 않고 알린다.
관련 할 일 ID 를 물어 머리말 `todo:` 에 적는다.

**add** — 옮길 파일과 대상 경로를 표로 보이고 **확인 후** 옮긴다.
- 파일 이름은 바꾸지 않는다. 다른 문서가 이름으로 가리키고 있을 수 있다.
- 같은 이름이 있으면 덮어쓰지 않고 묻는다.
- 옮긴 뒤 일지·회의록·todo 에서 옛 경로를 가리키는 곳을 찾아 목록으로 보고한다. 고칠지는 사용자가 정한다.

**index** — 폴더의 실제 파일과 목차의 `문서 목록` 을 대조한다.
- 목차에 없는 파일은 올리고, 없어진 파일은 목차에서 뺀다. 한 줄 설명은 문서의 제목과 첫 문단에서 뽑는다.
- `최신 문서` 는 가장 먼저 읽을 것 하나다. 날짜가 가장 최근인 보고·구성안을 후보로 제시하고, 애매하면 묻는다.
- `지금 상태` 는 그 과제의 가장 최근 일지 블록(`[T-NNN]`)의 `어디까지`·`다음` 에서 가져온다. 기록에 없는 내용을 쓰지 않는다.
- 같은 주제의 새 판이 나와 쓰지 않게 된 문서는 `old/` 로 옮길 후보로 제시한다. 확인 후에만 옮긴다.
- 머리말 `updated` 를 오늘로 바꾼다.

**sweep** — `records/` 에서 정해진 자리(daily·meetings·weekly·projects·team·inbox·_system) 밖에 있는 파일과,
`inbox/notes/` 에 7일 넘게 남은 파일을 찾는다. 파일마다 `보낼 과제(또는 새 과제) / 근거` 를 표로 제안한다. 옮기지 않는다 — 확인을 받으면 `add` 로 처리한다.

### Step 3 — 할 일 목록 연결

목차 머리말 `todo:` 의 ID 가 todo 에서 모두 완료·취소면 `status: 완료` 로 바꿀지 묻는다.
todo 항목에 `과제:` 칸이 없는데 그 과제의 일인 것이 있으면 칸을 붙일지 묻는다. 답한 것만 반영한다.

### Step 4 — 보고

```text
과제: <slug> (문서 n개, 최신: <파일>)
옮김 n · 목차 추가 n · 목차 제거 n · old 이동 n
옛 경로를 가리키는 곳: n곳 (목록)
```

이어서 `guides/GUIDE_CORE.md` §5 Self-Check 를 출력한다.

## 금지

- 확인 전 파일 이동·삭제 금지. 지우지 않는다 — 쓰지 않는 문서는 `old/` 로 옮긴다.
- 기존 파일 이름 변경 금지.
- 문서 본문을 고치지 않는다. 이 스킬이 쓰는 것은 `README.md` 와 todo 의 `과제:` 칸뿐이다.
- 과제 문서를 외부 서비스나 공유 페이지에 올리지 않는다.
