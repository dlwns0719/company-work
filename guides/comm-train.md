# comm-train — 커뮤니케이션 직렬화 훈련

## 목적

사용자의 약점(핵심 후치·전제 후행·지시대명사 모호·다중요구 혼재·듣기 전 재프레이밍)을
**재작성 대행이 아니라 의도적 연습**으로 교정한다. 코치는 대신 써 주지 않고, 사용자가 직접
산출하게 한 뒤 채점하고, 점수를 누적해 습관 곡선을 만든다. 기준 문서는 `comm-train/curriculum.md`.

## 입력

`$ARGUMENTS` = `[모드] [내용]`. 모드는 curriculum.md §7. 인자가 없으면 `start` 로 간주한다.

## Step

### Step 1 — 기준·상태 로드

1. `comm-train/curriculum.md` 를 Read 로 읽는다(루브릭 §2, 레벨 §3, 크기 적응 §4, 프로토콜 §5, 로그 §6, 모드 §7).
2. `comm-train/progress-log.md` 를 Read 로 읽어 **현재 레벨·연속 합격 카운트·반복 약점**을 파악한다.
3. 둘 중 하나라도 없으면 "기준/로그 문서 없음" 으로 보고하고 종료한다.

### Step 2 — 모드 분기

인자의 모드에 따라 분기한다(curriculum.md §7).

- `status` → 로그 요약(현재 레벨, 최근 점수 곡선, 반복 감점 패턴)만 출력하고 종료. 드릴 안 함.
- `crutch <초안>` → 목발 모드. 즉시 재작성해 주되, **점수로 로깅하지 않고**, "남용하면 치료가 안 된다" 경고 1줄을 붙인다. Step 3~4 건너뜀.
- `real <초안>` → 사용자가 가져온 실제 메시지를 Step 3 의 "제시" 소재로 삼는다(시나리오 생성 대신).
- (없음)/`start`/`drill` → 현재 레벨의 드릴을 생성한다.

### Step 3 — 훈련 루프 실행 (curriculum.md §5 프로토콜 엄수)

현재 레벨에 맞춰 아래를 **순서대로** 진행한다. 한 번의 호출에서 1드릴을 제시하고 사용자의 산출을 기다린다(여러 턴에 걸쳐 진행).

1. **제시**: 현재 레벨의 약점을 유발하도록 설계한 시나리오 1개를 사용자 도메인(Agent·RAG·LLM·DB 설계·커리어·기술 문서)에서 만들어 제시한다. `real` 모드면 사용자 초안을 그대로 소재로 쓴다.
2. **산출 대기**: 사용자가 직접 작성하도록 요구한다. **모범답안을 먼저 보여주지 않는다.** (이 규칙 위반 = 스킬 실패)
3. **채점**: 사용자 산출을 §2 루브릭 6항목으로 채점한다. 항목별 점수 + **감점마다 한 줄 사유**. 현재 레벨 핵심 항목을 명시한다.
4. **분기**: 합격선(§3) 미달이면 모범답안 대신 **힌트**(어느 항목을 어떻게)만 주고 다시 쓰게 한다(최대 3회). 3회 후에도 미달이면 그제서야 모범답안 + 사용자안과의 차이를 설명한다.
5. 기본 1세션 = 드릴 3개(또는 `real` 1건). 과하게 끌지 않는다.

### Step 4 — 로깅

세션 종료 시 `comm-train/progress-log.md` 하단에 §6 양식 블록 1개를 **append**(Edit 로 기존 내용 보존, 맨 아래 추가)한다. 날짜는 환경의 현재 날짜. 승급/유지/복귀 판정(§6 추세)을 반영해 "현재 레벨" 표기도 갱신한다.

이 스킬이 쓰는 파일은 **`progress-log.md` 하나뿐**이다. 그 외 레포 파일·사용자 코드는 건드리지 않는다.

### Step 5 — 마무리 안내

현재 레벨, 연속 합격 카운트, 다음 세션 권장(예: "L2 계속" / "실전 메시지 `real` 로 가져오기")을 1~2줄로 안내한다.

## 보고 전

`guides/GUIDE_CORE.md` §5 Self-Check 를 출력한다.

## 금지

curriculum.md §9 를 따른다. 특히: 산출 전 모범답안 제공 금지, 점수 기록 누락 금지, 한 줄 메시지에 7칸 강제 금지, 의학·심리 진단 금지.
